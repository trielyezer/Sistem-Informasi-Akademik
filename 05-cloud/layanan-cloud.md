# Layanan Cloud Computing untuk SIAKAD

## Kebutuhan
- Hosting aplikasi dan basis data (IaaS/PaaS)
- Penyimpanan berkas (cloud storage)
- Backup dan pemulihan (disaster recovery)
- Skalabilitas saat beban puncak (masa KRS, ujian, pengumuman nilai)
- Keamanan: enkripsi, firewall, kontrol akses

## Perbandingan dengan Penyimpanan Lokal

| Aspek | Komputer lokal | Cloud |
|---|---|---|
| Akses | Terbatas | Dari mana saja |
| Keamanan data | Rentan hilang | Backup dan perlindungan berlapis |
| Kapasitas | Terbatas | Mudah ditambah |
| Biaya | Investasi awal besar | Bayar sesuai pemakaian |
| Ketersediaan | Bergantung satu perangkat | Tinggi berkat redundansi |
