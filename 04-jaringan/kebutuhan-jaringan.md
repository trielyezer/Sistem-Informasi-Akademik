# Kebutuhan Jaringan SIAKAD

| Komponen | Contoh |
|---|---|
| Client | Smartphone, laptop, PC admin, printer |
| Server | Server basis data, server aplikasi/web, server backup |
| Media koneksi | Kabel UTP, serat optik, Wi-Fi, jalur ISP |
| Perangkat jaringan | Router, switch, access point, firewall, modem |
| Akses jaringan | LAN, Wi-Fi, Internet (HTTPS dan VPN) |

## Alur Koneksi
Client -> Access Point/Switch -> Router + Firewall -> Internet -> Server Aplikasi <-> Server Basis Data <-> Server Backup
