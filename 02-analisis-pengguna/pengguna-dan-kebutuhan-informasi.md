# Pengguna dan Kebutuhan Informasi

| Pengguna | Kebutuhan informasi utama |
|---|---|
| Mahasiswa | KRS, jadwal kuliah/ujian, nilai/KHS, IPS/IPK, presensi, tagihan, pengumuman |
| Dosen | Jadwal mengajar, daftar peserta kelas, input presensi dan nilai, data mahasiswa bimbingan |
| Admin akademik / staf prodi | Data induk, penjadwalan kelas dan ruang, rekap KRS dan nilai, laporan akademik |

## Mahasiswa
- Data pribadi dan status keaktifan
- Kartu Rencana Studi (KRS) dan daftar mata kuliah
- Jadwal kuliah dan ujian
- Nilai tiap mata kuliah, KHS, IPS, IPK
- Rekap kehadiran dan tagihan UKT/SPP

## Dosen
- Mata kuliah yang diampu dan jadwal mengajar
- Daftar mahasiswa peserta kelas
- Input presensi dan nilai (tugas, UTS, UAS)
- Persetujuan KRS mahasiswa bimbingan

## Admin Akademik
- Pengelolaan data induk mahasiswa, dosen, mata kuliah, dan kurikulum
- Penjadwalan kelas dan ruangan
- Laporan mahasiswa aktif/cuti/lulus dan statistik kelulusan
